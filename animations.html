Animated concepts

Motion with a purpose.

Animation should guide attention, not steal it. This page demonstrates five distinct animation concepts used across the portfolio: typing text, hover effects, an animated background, skill indicators and scroll reveals.

Concept 01 · JavaScript

Animated typing text

JavaScript cycles through a list of roles, typing and deleting one character at a time with setTimeout. A blinking CSS cursor completes the effect.

Concept 05 · IntersectionObserver

Scroll reveal

Content starts slightly lower and transparent. As it enters the viewport, an IntersectionObserver adds a class that fades and lifts it into place.

Tile 01 Fade in
Tile 02 Lift up
Tile 03 Staggered
Tile 04 On scroll
Tile 05 Smooth ease
Tile 06 Accessible
Reduced motion: if your device is set to reduce motion, these animations are disabled automatically. Content remains fully visible and the site stays easy to use.
